# 🤖 깨비AI 릴스 소스 다운로더

YouTube, X, Instagram, TikTok 영상을 URL 하나로 다운로드하는 웹앱입니다.

## Vercel 배포 방법

### 1. GitHub에 올리기
```bash
git init
git add .
git commit -m "깨비AI 다운로더"
git remote add origin https://github.com/YOUR_USERNAME/kkaebi-downloader.git
git push -u origin main
```

### 2. Vercel 배포
1. vercel.com 접속 → GitHub 로그인
2. "New Project" → 위 레포 선택
3. "Deploy" 클릭
4. 완료! URL이 생성됩니다

## 지원 플랫폼
- YouTube
- X (Twitter)
- Instagram
- TikTok

## 기술 스택
- Next.js 14
- cobalt.tools API (오픈소스)
